API Key Management

← Overview
Connect one or more market-data providers. The active provider is tried first; if it can’t fulfill a request (for example Finnhub free tier blocking year charts), the board automatically tries your other saved keys. Keys stay in this browser only.
Providers
Tip: keep Finnhub as active for live quotes, and also save Twelve Data or Alpha Vantage for 1Y charts — the board will fall back automatically when Finnhub history isn’t available. Since this page runs entirely in your browser, any key you enter is visible to anyone who views this page's source on a public site — fine for a low-stakes internal display, but avoid using this on a public repo if the key needs to stay private.
